# PetLux Premium

Премиум-сервис для владельцев домашних животных: приветственный лендинг + полноценное веб-приложение с бронированием, личным кабинетом и админ-панелью.

## Структура репозитория

```txt
petlux-premium/
├── index.html                 # Приветственный лендинг (точка входа)
├── app/
│   └── index.html             # Основное приложение (услуги, тарифы, бронь, кабинет)
├── config/
│   └── app.config.example.js  # Пример конфигурации Firebase/EmailJS
├── docs/
│   └── SETUP.md               # Подробная настройка backend
├── package.json
└── README.md
```

## Возможности приложения (`app/`)

- премиальный лендинг внутри сервиса (Hero, услуги, преимущества, тарифы, отзывы);
- онлайн-бронирование с выбором услуги, специалиста, даты и слота;
- анкета передержки (кормление, режим, привычки, количество дней);
- личный кабинет (регистрация, вход, история бронирований);
- календарь визитов;
- админ-панель (для роли `admin`);
- переключение светлой/тёмной темы;
- интеграция Firebase + EmailJS (через `config/app.config.js`).

## Быстрый старт

1. Установите зависимости не требуются (используется `npx serve`).
2. Скопируйте конфиг:

```bash
copy config\app.config.example.js config\app.config.js
```

3. Заполните ключи в `config/app.config.js`.
4. Запустите проект:

```bash
npm run dev
```

5. Откройте:
   - `http://localhost:3000` — welcome-лендинг
   - `http://localhost:3000/app/` — приложение

## Примечание

Файл `Премиум сервис для владельцев домашних животных.html` в корне — legacy-копия. Актуальная версия находится в `app/index.html`.
